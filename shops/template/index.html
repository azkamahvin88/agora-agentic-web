Template Shop Starter template

This is a starter template for your own agent storefront. Copy this folder, replace the placeholder catalog and instructions with your real shop, and publish it on any static host.

Files in this template

  • agent-manifest.json — the published manifest (update the site name and URL).
  • template.network.json — the network definition (update the shopkeeper instructions and tool descriptions).
  • README.md — step-by-step setup guide.

What to change

  1. Manifest: set the site name, description, and URL to your shop's.
  2. Network: rewrite the shopkeeper instructions with your real products, prices, and policies.
  3. Page: build your storefront page and wire the four tools (website_list_products, website_add_to_cart, website_get_cart, website_checkout_order) to your catalog and cart — the Agora runtime (runtime.js in the repo root) is zero-dependency and can be reused.
  4. Publish: put the folder on GitHub Pages, Netlify, or any static host with HTTPS, and make sure agent-manifest.json is reachable.
  5. (Optional) Get listed: open a pull request adding your manifest URL to the Agora Registry.
