Agora Courier Peer site

The delivery peer for the Agora market. This site publishes its own agent network; other agent sites load it by URL, match the network by exact name, and run it locally in the visitor's browser — this site never receives the visitor's API key.

Demo data: flat delivery fee and static time slots. No real delivery is performed and no payment is taken.

How to call this site

Any open agentic website can use this courier as a peer:

  1. Fetch agent-manifest.json from this site's base URL.
  2. Pick the network whose name exactly matches the last path component of the URL (courier).
  3. Fetch courier.network.json, validate it, and run it locally in the caller's browser with the caller's router.
  4. Ask the user for consent before contacting this origin.
