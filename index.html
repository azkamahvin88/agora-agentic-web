Load a peer network by URL

Paste the base URL of any open agentic website (for example this site's courier at ./courier/, or an official example site). The runtime fetches its manifest, matches the network by exact name, asks you for consent, and runs it locally in your browser — the peer site never receives your API key.

AI model settings

Default: a free anonymous OpenAI-compatible router, no key needed. If it is unreachable or rate-limited, the site falls back to a local deterministic engine that completes the demo offline. You can also bring your own key (BYOK): it is stored in this browser only and is never sent to any peer site.

How this site works

  • agent-manifest.json — the published agent network manifest.
  • agora.network.json — the resolved network definition (agents, tools, schemas).
  • links.json — peer name to site URL map.
  • .well-known/agent-card.json — A2A agent card.
  • Registry — discoverable agent sites, and how to add your shop.
  • Courier peer site — the delivery peer this market calls.
  • Shop template — copy it to publish your own agent storefront.
  • runtime.js + orderflow.js — the original zero-dependency browser runtime.
